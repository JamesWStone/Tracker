## Scenario: Create a simple website that allows a user to record and review learning activities completed during the week.
### The purpose is to demonstrate practical use of the HTML, CSS and Python skills already covered in James’s learning.

- HTML: create a clear page structure with a heading, navigation, a form for entering a learning activity, and a table or list showing completed activities.
- CSS: style the page so it is readable and professional, demonstrating selectors, the box model, colour, display and positioning.
- Python: write a small program to accept, validate or process learning entries and save/read them from a file. If connecting Python directly to the web page has not yet been covered, the Python component may be demonstrated separately alongside the website.
- Testing: check common inputs and document at least three tests, including one invalid or unexpected input.
- Evidence for review: provide the source files, screenshots or a short demonstration, a brief explanation of how the code works, and identify one improvement that could be made next.
Expected outcome: A working, clearly structured prototype that demonstrates independent application of existing learning. The emphasis is on showing understanding and explaining decisions, not on producing a production-ready application
